# Student Performance Predictor

This project predicts whether a student will pass or fail based on key features such as gender, study hours, and attendance percentage using a Decision Tree classifier.

## Features

- Loads and preprocesses student performance data
- Trains a simple Decision Tree machine learning model
- Interactive console input to predict pass/fail for new students
- Prints model accuracy on test data
- Easy to extend and integrate with Power BI or other visualization tools
